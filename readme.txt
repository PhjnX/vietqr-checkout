Vietnamese bank transfer with VietQR. Orders are confirmed automatically when the money arrives, through a SePay webhook.

== Description ==

Customers scan a VietQR code with any Vietnamese banking app. Bank, account, amount and transfer note are filled in for them. When the transfer arrives, SePay notifies the shop and the order is marked as paid within seconds.

* Payment code per order (DH1234), detected even when banks rewrite the transfer note.
* Webhook protected by API key, duplicate-safe.
* Partial payments, overpayments and late payments are noted on the order.
* Unpaid orders are cancelled after a configurable time and their stock is restored.
* Classic checkout and Checkout block. HPOS compatible.
* Vietnamese translation included.

== Installation ==

1. Upload the plugin and activate it. WooCommerce is required.
2. Set the store currency to VND.
3. WooCommerce > Settings > Payments > VietQR bank transfer: enter bank, account number, account holder and API key.
4. In my.sepay.vn > WebHooks, send transactions to the URL shown on the settings page with API Key authentication.

== External services ==

The QR code image is generated by the VietQR Quick Link service (https://img.vietqr.io). The customer's browser requests the image with the bank BIN, account number, account holder, amount and payment code of the order. No customer personal data is sent. Terms: https://vietqr.io

Payment confirmations are received from SePay (https://sepay.vn) when you configure a SePay webhook. The plugin does not send data to SePay.
